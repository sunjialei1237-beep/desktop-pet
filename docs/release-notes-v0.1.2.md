# Liri v0.1.2 — 她真的会搜、真的开了

> 发布日期：2026-08-27 · 全量安装包 / 便携版均可用，覆盖安装即可升级（数据不受影响）。

## 更新内容（自 v0.1.1）

### 搜索：听得懂"帮我找一找"了
- 修复：说"帮我找一找 / 找一下 / 找找 / 找一篇"这类最自然的请求时，此前她拿不到搜索工具、只能回"搜不到，你自己去看"——现在会直接去搜
- 生活话题不受影响："找工作 / 找实习 / 找不到"仍然不会触发工具轮

### 打开应用：不再"她说开了、桌面没有"
- `open_application` 启动后做差分进程校验（≤2.5s 轮询）：检测到新进程才说"已启动（检测到 xxx.exe）"
- 慢启动应用（抖音这类启动器+守护架构，冷启动窗口要几十秒）会如实告知"正在慢启动/可能已在后台"，不再过早打包票

### 设置面板（并行会话贡献）
- 面板可滚动、关闭按钮常驻、视觉整版陶土配色

### 其他
- lib 单测 560 → 564；媒体文件感知、多供应商、沉浸内心戏等 v0.1.1 能力全部保留

## 升级方式
- **已装 v0.1.0/v0.1.1**：直接运行新安装包，静默覆盖升级（`%APPDATA%\DesktopPet` 的记忆与配置不受影响）
- **新用户**：下载安装包，装完在首次启动向导里填 API Key 即可
