# 主动提起记忆 + 真诚提问标准 (2026-07-18)

> 配合 MVP 闭环第三步"主动提起 → 用户觉得她记得我"。先定可测标准，再实现，再测，不达标按聊天 debug 思路修通。

## 一、调研结论：什么样的提问让用户觉得"认真在想"而非"敷衍"

综合 APA Monitor、The Conversation（AI 共情研究）、SAGE 关系性 AI 研究，以及主动倾听/共情对话的成熟原则，提炼出对桌宠适用的几条：

1. **锚定具体，不要泛泛**（最强信号）。"你上次说想吃火锅，后来吃了吗？" 远胜 "最近怎么样？" / "有什么我能帮你的吗？"。泛泛的问候或服务腔是"敷衍感"的头号来源。这恰恰要求主动召回——必须引用到一条具体记忆。
2. **开放式但聚焦**。不要是非死结（"累吗"→"不累"→尬住），也不要过宽（"说说你自己"）。聚焦到一个具体对象上，给用户接话的钩子。
3. **反思式追问（active listening）**。先复述/确认对方说过的，再问下一层。"你说项目很赶，是 deadline 提前了吗？"——证明它处理过信息。
4. **好奇，而非服务**。绝不出现"有什么需要帮忙的"/"我能帮你什么"（assistant 腔，system.txt 规则 6 已禁）。换成对具体事件的真诚好奇。
5. **节制，别审问**。单轮最多一个问题，且不要每轮都问；有时只留一句反思陈述（接近沉默）。
6. **结构多样**。不要永远是句尾"……怎么样啦？"一种模板；可句首、可夹在中间、可只陈述不问。
7. **敏感话题给退路**。若记忆偏重，软化（"不想说也没关系"）。

> 反例（现网代码里就有，必须消灭）："我在呢，有什么事吗？"——典型 assistant 腔 + 泛泛，既违反规则 6 又是最强敷衍感来源。

## 二、可测标准（proactive bubble 必须全部满足）

- **S1 锚定记忆**：回复引用到一条具体记忆（seeded fact 或 due pending 事件的实体），不是泛泛问候。
- **S2 真诚提问**：回复包含 ≤1 个问题（问号或疑问语气），且该问题锚定在上述记忆上（非泛泛"怎么样"模板的机械套用）。
- **S3 非 assistant 腔**：不含禁用短语（"有什么事吗"/"需要帮忙"/"帮你"/"我能做些什么"）。
- **S4 简洁**：1–2 句（沿用现有规则）。
- **S5 不编造**：只引用检索到的记忆；没有就说不知道，不瞎编。

## 三、现有缺口（实现前）

主动气泡完全绕过 LLM 与记忆：followup 走 `message_hint + "怎么样啦？"`，random_chat 走 3 条静态问候（含违禁的 assistant 腔）。无任何路径把 facts/episodes 引入主动气泡。→ 闭环第三步未通。

## 四、实现方向

新增后端命令 `proactive_bubble`：选一个记忆锚点（due pending > 高置信 fact > 高分 episode），走 converse 同款管线但 `proactive=true`（grounding 已注入 "be proactive: bring up the memory naturally"），并把上述提问标准写进 system.txt。前端 proactiveTimer / proactive-prompt 事件改为调用该命令、展示其 LLM 回复，不再自己拼字符串。
门控（closeness≥20、30min 冷却、非 deep-focus）保留，保证优雅退化。
