# Liri · 璃 v0.1.0 —— 第一个安装包发布

一个有记忆、有情绪、会主动找你的 **Windows 桌面陪伴宠物**。

## 🚀 三步开始使用

1. **下载**：`Liri_0.1.0_x64-setup.exe`（一键安装，含桌面快捷方式与卸载器）；或 `Liri-0.1.0-x64-portable.zip`（免安装，解压即用）
2. **配置 API Key**：首次启动自动弹出配置向导 —— 粘贴 [DeepSeek API Key](https://platform.deepseek.com/)（免费获取），点「验证并保存」即可开口聊天（支持任意 OpenAI 兼容服务）
3. **可选：下载记忆模型**：向导中选择「立即下载」（约 570MB 本地 BGE-M3）。下载后她才真正「记得你」；跳过也能正常聊天

## ✨ 她是什么

- **记得你**：本地语义检索记忆，跨会话记得你们聊过的事；自然语言「忘掉 X」即可遗忘；答应过你的事到期会主动提起
- **懂你**：情绪持续漂移，低落时会主动冒「想你了」；有早安仪式、久别欢迎、深夜催睡
- **活着**：拖拽/摸头/戳/双击、视线 360° 跟随鼠标、发呆/张望/伸懒腰等微行为、真实 Foley 音效
- **会搭手**：查新闻（中文总结）、打开应用（自动扫描桌面快捷方式）、知道时间
- **隐私**：所有数据只存本机（`%APPDATA%\DesktopPet\`），只把对话内容发往你自己配置的 API 服务

## 📋 系统要求

- Windows 10/11 x64
- WebView2 运行时（Win11 自带；Win10 通常已内置，缺失时安装程序会引导安装）
