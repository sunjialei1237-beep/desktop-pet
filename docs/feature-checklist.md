## 已知问题汇总 (按优先级)

### P0 - 影响核心体验

1. **FSM 微行为与 Live2D 断链** — FSM 在正常运行但视觉无效。CSS 动画针对 `.pet-svg`, 而 Live2D 用 `<canvas>`。需要将 FSM 状态映射到 Live2D motion 调用。
2. **对话管道未端到端验证** — LLM 连接、记忆存储、检索、回复质量全链路从未在真实运行中测试过。现在 API key 已配好, 需要实跑验证。

### P1 - 用户已反馈的问题

3. **气泡位置** — 摸头文字出现在角色中间, 应在头部左上方。
4. **气泡透明度** — 用户希望更高透明度。
5. **摸头文字与输入框重叠** — 两者在同一位置, 需分开。
6. **摸头气泡加尾巴** — 用户希望气泡下方有圆圈指向角色。

### P2 - 功能缺失

7. **Foley 音效** — 完全缺失, 8 个 wav 文件未创建。
8. **关闭功能** — 右键"关闭"只显示气泡, 不实际退出。
9. **物理交互** — 自由落体/窗口边缘/回巢在窗口内坐标系下可能无效。
