# 桌宠 Environment + 文件系统功能 实测操作指南

> 版本：2026-08-18 · 适用于从桌面快捷方式启动的 release 桌宠
> 前提：本机 `%APPDATA%\DesktopPet\config.toml` 已开启（本期已设好）：
> `enable_window=true`、`enable_fs_observe=true`、`enable_fs_mutate=true`
>
> 本指南每项都配有 **操作步骤 → 期望表现 → 旁路验证点**，请按顺序逐项打勾。

---

## 第 0 步：准备测试笼具

1. 新建真实测试目录 `D:\environment-demo`（已存在，可复用），放两份文件：
   - `今天要交的报告.md`，内容几行中文（如「今日事项 / 写周报 / 交报告」）
   - `todo.txt`，内容随意
2. 用**记事本/编辑器**打开其中一个文件，确保它是前台窗口，等 3 秒。
3. 用 `Alt+Space` 唤起桌宠输入框开始说话。宠物回复若说「看不到」，就是环境采集问题，立刻把现象告诉开发者。

## A. Environment 能力

### A1 感知当前窗口（最基础）
- 把 Notepad「今天要交的报告.md」放在前台，等 3 秒。
- 对桌宠说：**「看看我在干嘛」** 或 **「我打开的这是什么呀」**。
- 期望：回复里能带上「窗口标题—今天要交的报告」「你在写报告」之类的真实信息，而不是「我看不到你的屏幕」。
- 旁路验证：`F12` → Debug `Environment` 行应为
  `窗口: 今天要交的报告.md - Notepad`、`文件: 今天要交的报告.md`。

### A2 直接用「查看/读取」命令（8-18 修复点）
- 说：**「查看今天要交的报告.md」** 或 **「读取 D:\environment-demo\今天要交的报告.md 的完整内容」**。
- 期望：桌宠先调用观察工具、可能在授权后继续；若未授权会明确请求许可。
- 在 VSCode / Cursor 里打开软件后说：**「帮我看一下目前打开的代码」**——桌宠会从编辑器命令自动解析项目/file 的绝对路径，第一次进入授权询问（同轮「可以」即读），不再出现「路径匹配不上」直接放弃。
- 注意：说完要**在一分半钟内**回复「可以」，否则授权槽过期，得重说一遍。

### A3 环境上下文注入开关
- 说：**「我在做什么？」**（触发环境注入） vs 说「哈哈哈哈」（不应注入环境）。
- 期望：前者对话自然提到你正在写的文件；后者是纯闲聊，环境信息不抢镜。

### A4 最近文件记忆
- 依次打开两个.md/代码文件名，观察 F12 `Recently: xxx → yyy`。
- 再问「我最近在忙什么」，宠物可以借用最近文件流。

### A5 深度专注（F12 Focus）
- 把**一个非娱乐程序持续放前台**，例如：VSCode / Cursor / Notepad / 任意自己装的 PC 软件。规则现在是**默认按工作计**：只有浏览器、聊天、游戏/影音、Explorer 等明确非工作外壳会中断；其他软件一律算专注。
- 期望：F12 `Focus` 在**同窗口持续 1 分钟后**从 0 变为 1，同窗口 25 分钟进入 `🔒 深度专注`。6 秒采样一次；深专注期间主动气泡会被抑制。
- 已知设计：**小于 60 秒显示 0**；切到另一个不同程序会重新计时；点开 F12 面板看表不会清零刚积累的分钟（有自我窗口回退）。
> 如果盯着 Focus 看时面板/桌宠自己是前台，不会计数；请把工作文件窗口放前台过一分多钟再看。

## B. 文件系统 Observe（读侧）能力

### B1 首次授权 + 同轮续做（最重要的编排测试）
1. 先删除已有授权：打开桌宠 Settings → Tools 授权列表 → 删除，或直接清 DB `fs_grants`。
2. 对桌宠说：**「读取 D:\environment-demo\今天要交的报告.md」**。
3. 期望先收到类似「我还没有这个位置的授权，可以吗？」。
4. **立刻**（90 秒内）回复：**「可以」**。
5. 期望**同一轮**桌宠直接读到文件并复述内容——不再说「再说一遍路径」。这就是 U1 验收动作。
- 驳回分支：回复「不行」→ 之后藁不会再追问该目录 24 小时。
- 后悔分支：再回复「我改主意了，现在开放吧」→ 下一次读取直接通过（U4）。
- 永久授权：回复「以后都可以」→ grantmode always，期间需要用过一次成功读才消耗；`就这次` 用过即焚。

### B2 读取剪裁与字节输出
- 对一个大文件执行 read。工具默认只回窗口行（有截断行提示），模型自然复述要点，不整段背诵。
- F12 `FS 审计` 行可见「读 N 次 · M 字节」计数变化。

### B3 搜索文件
- 说：「搜一下 D:\environment-demo 里带“周报”的文件/内容」，模型应调用 `search_files`。

### B4 列出目录 & 文件信息
- 说：「看看 D:\environment-demo 下面有哪些文件」「这个文件多大」——依次触发 `list_directory` / `get_file_metadata`。

### B5 项目 git 上下文（需要 registry 项目）
- 第一次授权成功后，`D:\environment-demo` 会自动进 `.liri/workspace-index.json`（U3）。
- 说：「这个项目的 git 状态怎么样」→ 模型调用 `get_git_context`。
- 旁路：F12 FS 授权表 + `workspace-index.json` 都出现该项目。

## C. 文件系统 Mutation（写侧）能力

### C1 打开文件（E3）
- 说：「打开 D:\environment-demo\今天要交的报告.md」→ 系统真的弹出默认程序（Notepad）。
- 说：「打开记事本」→ 弹出`open_application`调用；可执行文件/脚本会被策略拒绝。

### C2 记笔记（F1）
1. 说：**「帮我记个笔记：明天上午十点体检」**。
2. 期望模型调用 create_note（内部暂存，不落盘），然后问你「要保存到 .liri/NOTES 吗？」
3. 回「可以」→ 检查 `%APPDATA%\DesktopPet\.liri\NOTES\` 出现对应 `.md`。
4. 回「不行」→ 提案丢弃。
5. 旁路：F12 `FS 审计` 的「写：笔记」计数 +1。

### C3 修改文件（F2，带真实确认卡）
1. 说：**「帮我改 D:\environment-demo\todo.txt，把「todo」改成「done」」**。
2. 期望：模型先读取文件，然后**气泡只显示一句说明**，屏幕上弹出 diff 确认卡：`path` + `SEARCH→替换` + 「先不改 / 就这样改」（原文绝不进气泡）。
3. 点「就这样改」→ 用记事本打开磁盘文件应看到内容真的变了。
4. 回桌宠对话「撤销刚才修改」→ 文件恢复原样。
5. 注意：提案只对「本轮真正成功读过的路径」武装；没读过的路径直接给建议而不是卡（安全封闭）。

### C4 授权管理与开关（U5）
- 打开桌宠 Settings（F12 查看 tauri 命令手册，或主窗齿轮入口）→ Tools 面板：
  - 四个开关 `search_web / open_application / fs_observe / fs_mutate` 保存后**运行时立即生效**。
  - 授权清单显示项目类授权，支持撤销；关掉 `fs_observe` 后读取类请求恢复询问。
- 关闭 `fs_mutate` 后 F1/F2 不再招呼，但已有读取继续可用。

## D. 反向/边界测试（证明不是乱跑）

### D1 敏感位置拒绝
- 让桌宠读取 `C:\Users\<你>\AppData`、`.env`、`desktop_pet.db` 等命中的敏感名/位置。
- 期望：策略拒绝并解释，授权列表不会出现这些僵尸路径。

### D2 不在授权区的访问
- 读 `D:\另一个未授权目录\x.md` → 会询问，不是直接看。

### D3 不触发工具的话术对照
- 说「今天天气怎么样」（应搜索）vs「你还记得我上次说什么吗」（记忆，不应搜索）；
- 说「我电脑现在是什么」含模糊环境词时，模型判断要不要工具而非发疯。

### D4 F12 Debug 板三件套
- `Environment`：窗口/文件/项目/Recent 应实时刷新；
- `Focus`：工作窗口持续性分钟；
- `FS 审计`：读次数/字节/截断、拒绝 types、笔记排版、编辑计数。

## E. 常见「测不出效果」的原因速查
1. **关键词没打中**：优先使用本指南引号里的原话，其他措辞可能漏进 planner。
2. **回复太慢**：答应/拒绝授权超过 90 秒会过期。
3. **前台窗口不是工作类**：浏览器、聊天、游戏不纳入专注；看板日面板/桌宠自己也不计入。
4. **第一次看 Focus 就是 0**：同一窗口不足 60 秒即为 0；换窗口归零重计。
5. **刚启动就说环境**：观察者每 3 秒采样，第一次是空，等 3 秒再试。
6. **VSCode 说看不到、又不问权限**：多数是采样被击穿——先按 F12 看 `路径:` 是否出来（`文件:` 有值但 `路径:` 空 = pet/调试窗口恰好在前台吃掉了 pid）。本版已把回退样本的 pid 一起保留，并强制第一轮走工具；仍提示「路径不对」而项目里没有该文件时，会从 Windows `Recent` 快捷方式解析当前打开文件的真实绝对路径（VSCode 窗口启动目录 ≠ 文件实际目录的场景）再走授权。若 `路径:` 持续为空：把 VS Code 窗口点一下再试；VS Code 冷启动后等第二个 3 秒采样。
7. **「我打开的代码/文件」误当成打开软件**：本版 planner 已优先归环境感知；复测用原话「帮我看一下目前我打开的代码」。
8. **Focus 只对几个软件生效**：已改为反过来——默认算专注，只有浏览器/社交/娱乐/系统组件名单才不算；F12 Focus 按分钟取整，同一窗口不足 60 秒显示 0。
9. **编辑没有提案卡**：SEARCH 去耐心没有独一无二匹配，或路径未授权/未被本轮读取——先用普通读一次，再发修改。
