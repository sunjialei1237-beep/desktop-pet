## 胜利明细

1. **套路提问大规模消退**：G3 闲聊 50%→10%，G12 分享 80%→30%（−50pp）。基线 G12 几乎每条追问（"肥瘦怎么样？""晚饭吃过了吗？""是金桂还是银桂？"），修改后多数用一句接住的话收住（"红烧肉啊，食堂这是放大招了。"）。
2. **G5 克隆开场治愈**：基线 502/503/505/507/508 五条全以"哇"开头；修改后 0/10，开场多样（满分！／赢了？／涨工资啦？／恭喜呀／面试过了？）。
3. **"想听细一点的我可以再讲"消失**：基线 101 的 AI 客服尾巴，修改后 G1 回复干净收住。
4. **提问质量上升**：当修改后仍提问时，全是内容相关的具体追问（1207"汤头喝干净了没"、1208"有记下名字吗"、1209"第一杯打算泡什么喝"），无一条套路"怎么样"——改动 C 生效。
5. **G7 提醒真人感反升** 3.7→3.9：基线机械，修改后更自然。

## 两个权衡（诚实交代）

### 权衡 1：human_like 4.24→4.11（−0.13）

**原因：回复变短了，不是变冷。** judge 备注高度一致："稍显简短，略欠一点情绪起伏"（502/504/506/507/1201/1204/1206）。A3 新规则"像随手发消息…可以嗯/哎/半句话/一个字"被 LLM 用足，倾向更短。回复依旧温暖、具体、贴题（logical/on_topic 全 5.0），只是更克制。

**判断**：真人本就常发短消息。4.11 仍稳在 4+。这更贴近用户"不够真人感"的诉求方向（真人 ≠ 话多）。若用户觉得 G5 喜讯偏冷，可微调 A3 不鼓励"一个字"（见末尾可选微调）。

### 权衡 2：模板词 23→23 纹丝不动

**构成迁移了，不是没改善**：基线"哇"占 G5 开场 5/10 → 修改后 0/10；但"恭喜/棒/厉害"上来了（503/504/506/508 恭喜、501 太棒）。**而"恭喜"对喜讯是正常人类反应，非 AI 味**——强行把"恭喜"砍到 0 才是"为了达标牺牲自然"。真正病灶（克隆开场、客服尾巴）已除，模板词计数持平是**指标artifact**而非倒退。

### G14 碎念 40% 为何不压更低

修改后 G14 的 4 个提问全对**天然邀请追问**的输入：1401"在吗在吗在吗"→"是有什么事"、1402"啊啊啊啊"→"好消息还是气着了"、1405"想起来一个事"→"什么事了"、1407"猜猜我干了什么"→猜测。压到 0 等于对"啊啊啊"回"嗯"——反人类。这恰是用户设分档指标时强调的"G5 喜讯高提问率是真好奇不是套路"的同类情形。**保留这 40% 是对的。**

## 可选微调（不急，待用户定夺）

- **若要回调 G5 温度**：把 A3"可以嗯/哎/半句话/一个字"软化为"可以简短，但别只剩一个字"，让喜讯回复多留半句情绪（如"满分！够你开心一整天的。"）。代价：human_like 可能回升 0.1，但全局提问率不受影响。
- **G12 记忆幻觉**（1202/1210 judge 标"声称用户之前提过"）：属记忆 grounding 守卫范畴，非本调教 scope，另案处理。
